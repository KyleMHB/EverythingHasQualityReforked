# Use inherited rules and restart-based activation

Accepted in the consolidated plan on 18 October 2026. Resolve item exceptions before the most specific matching category branch, then the quality group's default; an equally specific conflict resolves to Exclude. Assignment and optional effects have distinct controls so existing native quality can be retained while added behavior is excluded.

The options edit a draft, Save persists the next-session configuration, and the running session keeps its active configuration until restart. This replaces live component rebuilding and inconsistent partial application with a predictable lifecycle. It deliberately trades immediate feedback in gameplay for preservation of unrelated component state; the options still preview effective rules and pending changes immediately.
